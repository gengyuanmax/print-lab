元素实验室Element Lab元素实验室Element Lab

一个元素放进 Swiss / Riso / 半调风格里总觉得“不搭”，通常是因为它没有走同一条印刷管线。这里把一个元素拆成几步翻译：每一步可以单独开关，看改造前后放在同一张纸上的样子，并逐条检查哪里还不适配、规则出自哪里。When an element feels out of place in a Swiss / Riso / halftone design, it usually has not gone through the same print pipeline. This lab translates one element step by step: switch each step on or off, compare before and after on the same paper, and check what still does not fit and where each rule comes from.

    单张图片的处理Moves on one image IMAGE

    在翻译之前先动图片本身：裁切、镜像、抠图、切条、重复、错位复制、斜放、剪影 / 线稿、放大网点、扫描拖影。它们决定图片在版面上“说什么”，翻译步骤决定它“怎么印”。改造前后都会套用。Work on the picture itself before translating it: crop, mirror, cut out, slice, repeat, echo, tilt, silhouette or line art, giant dots, scanner drag. These decide what the image says on the page; the steps decide how it prints. Both before and after use them.

    两个元素的运算Two elements OPERATIONS

    两个元素放在一起时，可以叠印、镂空、反白，也可以做布尔运算。印刷里关键的问题是：两块版对不准时，结果还站得住吗？Two elements can overprint, knock out or reverse, or be combined with boolean operations. In print the key question is whether the result survives when the two plates miss.
