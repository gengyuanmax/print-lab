元素实验室Element Lab元素实验室Element Lab

网页组件、图形和照片怎样融入瑞士风格、Riso 和半色调设计？“改造”模式逐项调整配色、线条和网点，对照改造前后的变化；“组合台”可自定义一个或两个元素，尝试单元素处理和双元素组合。各项说明附有参考来源。When an element feels out of place in a Swiss / Riso / halftone design, it usually has not gone through the same print pipeline. Translate takes one element through the steps, each switchable, and checks what still does not fit and where each rule comes from; the Composer lets you define one or two elements and try single-element moves and ways to combine them.

规则启用情况Fit check (after)

    模式Mode MODE

    “改造”模式逐步调整现成示例的印刷风格；“组合台”由你设置元素内容，既可处理单个元素，也可比较两个元素的组合效果。Translate takes a ready-made element into the print style step by step; the Composer lets you define one or two elements yourself and try single-element moves and ways to combine two.

    组合台Composer COMPOSER

    先选定要编辑的元素，设置内容、配色、大小、角度和处理效果，再选择组合方式。可在画布上直接拖动元素，也可点击对照样张切换效果。Define the elements (type, content, ink, size, angle and single-element moves), then pick a way to combine them. Drag the elements on the sheet; the panel beside it compares every option, click one to switch.

    组合方式Combine OPERATION

    A 为下层，B 为上层。调整套色偏差，观察交界处的白缝或重叠。同色元素的主体按同一色版处理；异色复制和投影等效果仍可能引入其他色版。A is below, B on top. In print the key question is whether the result survives when the two plates miss. If both use the same ink they share one plate and cannot miss each other.
